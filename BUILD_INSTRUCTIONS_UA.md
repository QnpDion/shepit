# Shepit 1.2 — інструкція зі збірки Android APK

## Що реалізовано

У версії **1.2.0+3** Shepit отримав оновлений щоденний сценарій: на стартовому екрані з’являється одна картка з передбаченням, цитатою або висловом. Вибрана картка зберігається для поточної календарної дати й не змінюється до наступного дня.

Користувач може залишити режим **«Випадково»** або перейти в **«За темами»** та вибрати групи «Тихий знак», «Сміливість», «Стосунки», «Дорога» і «Самопізнання». Додано «Обране», компактний розгортний архів на головному екрані, повний архів за місяцями, світлу/темну тему, параметр одного щоденного нагадування та вимкнення м’яких анімацій.

На Android також додано віджет «Шепіт дня». Він показує короткий текст активної картки та оновлюється після відкриття застосунку. Логотип виконано як чистий нативний векторний знак: темний слід-шепіт навколо теплої іскри.

## Мова застосунку

У налаштуваннях користувач може обрати **«Як у системі»**, **українську** або **англійську**. Якщо залишено системний режим, застосунок автоматично використовує українську для української системної локалі та англійську як безпечний fallback для інших локалей.

Обраний режим визначає не лише заголовки та кнопки. Локалізованими є також **тип картки, її назва, передбачення, цитата, коротка дія, щоденне нагадування й текст Android-віджета**. Після ручної зміни мови картка зберігає свій зміст і дату, але одразу показується відповідною мовною версією.

## Збірка у Codemagic

1. Розпакуйте ZIP так, щоб `pubspec.yaml` і `codemagic.yaml` лежали в корені репозиторію.
2. Замініть у репозиторії попередні файли папкою з цього пакета або завантажте її як новий стан проєкту.
3. У Codemagic виберіть workflow **`android-apk`**.
4. Запустіть нову збірку. Workflow послідовно виконує `flutter pub get`, `flutter analyze`, `flutter test` і `flutter build apk --release` на JDK 17.
5. Після успіху завантажте APK із секції **Artifacts**.

> Для цієї технічної версії release APK, як і раніше, підписується debug-ключем. Це придатно для тестування та встановлення вручну, але перед публікацією у Google Play потрібно налаштувати окремий release keystore.

## Перевірка перед запуском збірки

Переконайтеся, що в репозиторії збережено нові файли з `lib/`, `assets/` і `android/app/src/main/`. Не видаляйте `codemagic.yaml`: у ньому вже зафіксовано Java 17 і чотири послідовні кроки контролю якості.
